# Agent Instructions

## Project Overview

A Python application for editing recorded video files by removing unwanted segments and generating a separate edited video file.

## Project Guidelines

- Use Python 3.14 or newer.
- Use pip for dependency management.
- Use a local virtual environment (.venv).
- Keep application source code under src/video_editor/.
- Keep tests under tests/.
- Store original recordings under input/.
- Store generated recordings under output/.
- Never modify or overwrite original recordings.
- Prefer simple, modular, maintainable code.
- Minimize third-party dependencies.
- Record required Python dependencies in requirements.txt.
- Consider MoviePy for video processing.
- Do not introduce unnecessary abstractions or frameworks.
- Implement only explicitly requested features.
- Ask for clarification when requirements are ambiguous.
- Update README.md when setup or usage instructions change.
